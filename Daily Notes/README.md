# 📅 Daily Notes

> "Small daily reflections compound into deep insights."

This folder stores daily journal entries, automatically created by the Daily Notes core plugin.

## Configuration

- **Folder:** `Daily Notes/` (set in `.obsidian/app.json`)
- **Naming:** `YYYY-MM-DD.md` (e.g., `2026-09-25.md`)
- **Template:** `04 - Templates/Daily Note Template.md`
- **Auto-create on startup:** Enabled
