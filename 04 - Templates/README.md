# 📋 Templates

> "Consistency is the foundation of a reliable second brain."

Standardized templates for consistent note creation across your vault.

## Templates

| Template | Description |
|----------|-------------|
| [[Daily Note Template]] | Daily journal with morning reflection, wins, challenges, and notes |
| [[Zettelkasten Template]] | Atomic knowledge note with summary, details, connections, and sources |
| [[Project Template]] | Project tracker with goal, status, tasks, resources, and notes |

## Usage

- **Daily Notes** — Auto-bound in `.obsidian/app.json`; creates a new journal each day
- **QuickAdd** — Use the QuickAdd plugin to bind any template to a hotkey or command
- **Templates Plugin** — Core plugin can insert these via `Ctrl/Cmd + P → "Templates: Insert template"`
