# Second Brain

A personal knowledge base / digital garden built with [Obsidian](https://obsidian.md).

## Structure

- `00 - Inbox/` — Quick capture area for new notes
- `01 - Notes/` — Permanent notes (atomic notes)
- `02 - Projects/` — Active project notes
- `03 - Resources/` — Reference material
- `04 - Templates/` — Note templates
- `05 - Archive/` — Inactive/completed items
- `Daily Notes/` — Daily journal entries

## Sync

This vault is version-controlled with git and pushed to `github.com/manikumarandugula77-coder/second-brain`.
