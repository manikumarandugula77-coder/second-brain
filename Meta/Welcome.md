# Welcome to Your Second Brain

> "Your mind is precious. Don't lose what's in it."

## About This Vault
This is your personal **Second Brain** powered by Obsidian, connected to GitHub for version control and backup.

## Structure Overview
- **00 - Inbox**: Capture quick thoughts and fleeting ideas
- **01 - Notes**: Permanent notes and knowledge base
- **02 - Projects**: Active projects and tasks
- **03 - Resources**: External materials and references
- **04 - Templates**: Note templates for consistency
- **05 - Archive**: Old notes and completed projects
- **Daily Notes**: Daily journals and reflections
- **Meta**: Vault configuration and meta-information

## Getting Started
1. Start with capturing thoughts in the Inbox
2. Process Inbox items into permanent notes
3. Link notes together using [[Wiki Links]]
4. Use tags (#) for quick categorization
