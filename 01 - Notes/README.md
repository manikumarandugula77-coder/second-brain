# 📚 Notes

> "Where fleeting thoughts become permanent knowledge."

This is your **Zettelkasten** — the permanent, atomic knowledge base. Each note should be:
- **Atomic** — one idea per note
- **Linked** — connected to other notes via `[[Wiki Links]]`
- **Self-contained** — anyone can read it standalone

## Workflow

1. **Create** — Use the Zettelkasten Template (`04 - Templates/Zettelkasten Template.md`)
2. **Link** — Reference other notes, tag with `#topic/tags`
3. **Refine** — Over time, improve and connect notes into a web of knowledge
