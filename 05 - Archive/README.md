# 🗃️ Archive

> "Out of sight, not out of mind."

Completed projects and old notes moved out of active rotation. This keeps your active folders lean and focused.

## Workflow

1. **Archive** — When a project is done or a note is no longer active, move it here
2. **Preserve** — Archived items are still searchable and linked
3. **Review** — Periodically audit the archive for rediscovered insights
